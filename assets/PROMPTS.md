# Expedition Venery — Art Generation Record

All assets generated with the MiniMax CLI (`mmx image generate`, model `image-01`).
Every command was run with a fixed integer `--seed`, so `seed + prompt` reproduces the
exact file. Common flags: `--width` / `--height` (multiples of 8), `--out`, `--quiet`.

Regenerate any row with:

```
mmx image generate --prompt "<prompt>" --width <w> --height <h> --seed <seed> --out "<path>"
```
